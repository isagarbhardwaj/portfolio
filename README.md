# Creative Portfolio UI

A modern and visually striking portfolio landing page built with HTML and CSS, focused on mastering `position: relative` and `position: absolute` for precise layout control.

The design features:

- Pixel-perfect creative portfolio layout
- Layered cards and floating UI elements
- Clean grid-based structure
- Modern typography and color palette
- Responsive alignment techniques
- Advanced positioning using CSS

This project is ideal for practicing frontend layout skills and recreating professional UI designs from references.

## Technologies Used

- HTML5
- CSS3

## Focus Areas

- Relative & Absolute Positioning
- Flexbox Layout
- UI Spacing & Alignment
- Modern Card Design
- Responsive Structure
